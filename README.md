# Jarvis — голосовой ассистент для Windows

Десктопный голосовой помощник на Python. Слушает микрофон, распознаёт русскую речь, отвечает голосом и управляет компьютером. Нейросеть работает **локально** через Ollama — никакие данные не уходят в облако.

## Возможности

- 🎤 **Распознавание речи** — через `speech_recognition` + Google (ru-RU), запись на `sounddevice` (без pyaudio)
- 🔊 **Русская озвучка** — RHVoice, голос «Михаил» (SAPI5)
- 🧠 **Локальная нейросеть** — Ollama, ответы на любые вопросы
- 🖥️ **GUI** — тёмное окно на Tkinter: лог диалога, статус, ручной ввод
- 📂 **Управление приложениями** — «открой телеграм», «закрой хром» (поиск по ярлыкам и процессам)
- 🌐 **Открытие сайтов** — «открой youtube.com»
- 🔊 **Громкость** — «громче», «тише», «выключи звук»
- ⏰ **Напоминания** — «напомни через 5 минут ...»
- 💻 **Системные команды** — время, выключение, перезагрузка, MAC-адрес
- 🔄 **Автообновление** — проверка новых версий через GitHub Releases
